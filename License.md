# Licenses and asset notes

NOVA Desktop is supplied as a project prototype. Its HTML, CSS and JavaScript are original project code for this delivery. The interface uses CSS-rendered glyphs and system fonts; no third-party icon pack, external font, commercial audio, or remote image asset is bundled. The project imports no external JavaScript libraries.

If you extend this project with libraries, fonts, images, sounds or game assets, review each item's license and add the relevant attribution here before redistribution.
